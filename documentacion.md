1) Averiguar como se documenta código explicando diferencias entre backend y fronted
  Front-end: es la parte de una aplicación o página web que el usuario ve y utiliza. Incluye botones, menús, formularios, colores, imágenes
 y diseño. Se desarrolla principalmente con HTML, CSS y JavaScript, y también con herramientas como React.
Back-end: es la parte que funciona detrás de la aplicación. Se encarga de la lógica, servidores, bases de datos, usuarios, autenticación
 y procesamiento de información.
Ejemplo:
En una página para iniciar sesión:
Front-end: muestra los campos de usuario y contraseña y el botón "Iniciar sesión".
Back-end: recibe esos datos, los verifica en la base de datos y decide si permite entrar.

2) Averiguar como se documenta código para javascript
  El código JavaScript se puede documentar mediante comentarios y JSDoc.
JSDoc permite explicar qué hace una función, sus parámetros y qué información devuelve.
Las etiquetas más utilizadas son:
@param: describe los parámetros.
@returns: describe lo que devuelve una función.
@example: muestra cómo utilizar una función.

3) Averiguar como se documenta código pare react en especifico
En React se documentan principalmente los componentes, propiedades (props), funciones y estados.
Se pueden utilizar comentarios y JSDoc para explicar el funcionamiento de los componentes.
También se puede utilizar TypeScript para indicar los tipos de datos que reciben los componentes mediante sus props,
 lo que facilita entender y mantener el código.
